Production ML Engineering, Serving & Monitoring

Production-style infrastructure implementation: Feature Store (offline/online), zero training-serving skew pipeline, model packaging and versioning, REST API microservice, and statistical drift monitoring (KS-Test & PSI).

🗄️ Feature Store

Entity Key: StudentID

Dual-tier feature store providing offline historical slices for model retraining and sub-millisecond online key-value retrieval for real-time inference.

🛡️ Skew Prevention

Zero-Skew Pipeline

Transforms (imputation, one-hot encoding, standard scaling) are serialized inside a single Scikit-Learn ColumnTransformer pipeline artifact to guarantee identical inference math.

📦 Model Packaging

Packaged Bundle v1.0.0

Standardized artifact package containing placement_pipeline.joblib, cryptographic data hash, feature schemas, and metadata manifest.

📡 Drift Monitoring

KS-Test & PSI Guard

Continuously tracks data drift via 2-sample Kolmogorov-Smirnov test and Population Stability Index (PSI threshold = 0.20) to detect distribution shifts.

REST-Based Serving Endpoints

Production endpoints available on this service for external client consumption and automated pipelines:

POST /api/v1/predict/placement Single or batch placement prediction & confidence
curl -X POST http://localhost:5000/api/v1/predict/placement -H "Content-Type: application/json" -d '{"CGPA": 8.7, "CodingTestScore": 92, "AttendancePercent": 88, ...}'
POST /api/v1/predict/salary Continuous regression package estimator
curl -X POST http://localhost:5000/api/v1/predict/salary -H "Content-Type: application/json" -d '{"CGPA": 9.1, "Projects": 4, ...}'
GET /api/v1/features/<student_id> Online Feature Store lookup by StudentID
curl -X GET http://localhost:5000/api/v1/features/101
GET /api/v1/model/metadata Inspect active model version and manifest
curl -X GET http://localhost:5000/api/v1/model/metadata
